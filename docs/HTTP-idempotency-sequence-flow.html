Where the guarantee comes from

○Declaredthe HTTP method — a promise, readable by every hop
○HonouredHTTP transport / SDK — decides whether to re-send
○Honouredproxy, LB, service mesh — retries without asking you
○Suppliedyour handler — keys, fingerprints, guards, status codes
○Enforcedthe database — the only layer that can arbitrate

What each layer can and cannot see

Every hop above your handler makes its decision from the method alone. None of them can inspect what your code does. That asymmetry is the whole reason a mislabelled handler is dangerous rather than merely untidy.

The shape of the thing

The method declares. The middle layers obey. Your code supplies the mechanism. Only the database enforces. Every duplicate you have ever debugged came from a gap between two of those four verbs.

The corollary worth memorising

Application code can coordinate but cannot arbitrate. Two pods, two goroutines, no shared memory — a check in Go is a guess about a moment that has already passed. Push the decision into one SQL statement and let the index answer it.
